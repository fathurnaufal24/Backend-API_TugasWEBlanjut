# Backend RESTful API - Sistem Manajemen Inventaris Produk

## Judul Project
Sistem Manajemen Inventaris Produk Berbasis Web

## Latar Belakang
Pengelolaan data barang secara manual berisiko mengalami kekeliruan pencatatan dan kurang efisien. Diperlukan layanan API terpusat untuk memproses data barang secara real-time.

## Solusi & Tujuan
Membangun RESTful API performa tinggi menggunakan Bun dan ElysiaJS untuk menangani seluruh operasi CRUD data produk.

## Rincian Fitur & API Endpoints
- `GET /api/products` : Menampilkan seluruh data produk
- `POST /api/products` : Menambahkan data produk baru
- `PUT /api/products/:id` : Mengubah data produk berdasarkan ID
- `DELETE /api/products/:id` : Menghapus data produk berdasarkan ID
